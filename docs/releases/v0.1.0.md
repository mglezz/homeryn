# Homeryn 0.1.0 — Your home, in sync.

The first local Windows release brings shopping lists and household chores into one small desktop app.

## Included

- Shopping items with quantities and reversible purchase status.
- Chores with optional assignees, due dates, and reversible completion.
- SQLite persistence, migration from the first shopping schema, and protection against stale edits.
- Draft protection, explicit New/Save actions, and clear connection/conflict feedback.
- Consistent online backups with a documented recovery workflow.
- A portable Windows x64 ZIP with the .NET runtime and local server included.
- Enforced loopback listeners, bounded connections, and deadlines for idle or incomplete requests.
- Bundled .NET 10.0.14 runtime with a gate that rejects outdated runtime packages.

## Download and run

Download **Homeryn-0.1.0-win-x64.zip**, extract the whole folder, open **Homeryn.Desktop.exe**, and click **Start server**. No .NET installation is required. Read **START-HERE.md** in the ZIP for backup, recovery, and update instructions. **SHA256SUMS.txt** contains the package checksum.

## Release scope

Windows 11 x64, one computer, one shopping list and one chore list. The server listens only on loopback. Assignees are free text; there are no accounts, permissions between local clients, invitations, remote access, reminders, or recurring tasks. Refresh is manual. The executable is unsigned, and there is no installer or automatic updater.

Back up before updating or experimenting with data. A five-second list-load deadline protects responsiveness; very large lists and long-running use have not been qualified. Full DPI/accessibility coverage and testing on a physical machine without .NET remain follow-up work. Self-contained packaging is checked by inspecting runtime metadata and running the extracted package on Windows.

## Verification

The security gate scans Git history for secrets and checks direct/transitive NuGet dependencies for known advisories. External Actions and the scanner are pinned; packages reject databases, keys, environment files, and local debug/IDE files. See the [security policy](https://github.com/mglezz/homeryn/blob/main/SECURITY.md). Local clients are unauthenticated, stored data is unencrypted, and this release is not intended for hostile or shared-user machines.

The release workflow builds with warnings treated as errors, runs the integration suite, publishes both applications, and tests the extracted package outside the repository. Package checks cover desktop startup, TCP operations, stale-write rejection, online backup, and recovery. Release assets are published only after these checks pass.
