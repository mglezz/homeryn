# Homeryn

### Your home, in sync.

I'm building Homeryn to make sharing a home a little easier. I want to bring shopping lists, household chores, and shared responsibilities into one place, so there is less to remember and less to chase up.

Whether I need to add milk to the shopping list or check whose turn it is to clean the kitchen, my aim is to make everyday coordination simple.

## What I'm working towards

I plan to make it possible to:

- Share shopping lists with the people at home.
- Add products and mark them as bought.
- Create chores, assign them, and mark them as done.
- Keep everyone in a household up to date.
- Save household information for the next time the app is opened.

I am designing Homeryn with families, couples, and roommates in mind. These are planned features; they are not available yet.

## Where I am now

**I'm building the first working foundation. There is no release ready for everyday use yet.**

I can now check that the desktop app's connection code exchanges a simple message with a local server. I have also checked that several connections can work at the same time.

I'm creating the desktop interface separately in Visual Studio. I still need to add its connection button before I can try that check directly from the window.

I haven't added shopping lists, chores, accounts, invitations, or saved household information yet. For now, my connection tests stay on one computer.

## Why I'm building it

I started Homeryn as my final project for Distributed Systems and Parallel Programming. I also want to keep developing it into a useful application and a project I can include in my portfolio.

My approach is to start small, understand each decision, and add features step by step.
